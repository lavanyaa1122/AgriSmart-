# AgriSmart — Grow with Intelligence

A responsive, visual smart-agriculture front-end prototype with an illustrated farm hero, animated cards, sample field snapshot, irrigation demand calculator, soil/weather view, checkpoint route planner, scripted farmer assistant, and project information page.

## Features
- Responsive dashboard with CSS-drawn 3D/isometric-style crop field illustration.
- Interactive soil moisture, temperature, and humidity sliders.
- Rule-based illustrative irrigation demand index and visual breakdown.
- Environment snapshot and flowchart-style model explanation.
- Selectable field checkpoints with an illustrative route preview.
- Scripted farmer assistant with suggested prompts.
- Interactive field checklist, mobile navigation, and demo information modal.

## Important limitations
This is a static learning prototype. It does not connect to real sensors, live weather, GPS/maps, or a live AI model. Values, route geometry, and responses are illustrative only and are not agronomic advice. Google Fonts are loaded from the internet; system fallbacks are provided.
